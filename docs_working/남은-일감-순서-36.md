# 남은 일감 순서 — 33·34·35번 통합

[33번](클라이언트-캠페인-상세구현계획-33.md)·[34번](데스크톱-성능-게임패드-언어-정적검토-34.md)·[35번](스토리-액션-리디자인-구현계획-35.md)에서 2026-11-06 기준으로 끝나지 않은 일감을 실행 순서대로 하나로 모았다. 위에서부터 차례로 한다. 각 항목에 필요한 선행 작업은 모두 그보다 위에 있다. 원문 ID의 상세 절이 구현 방법과 완료 조건의 원본이고, 완료하면 원문의 체크박스와 이 목록의 체크박스를 함께 체크한다. 1~30번은 에이전트가 혼자 끝낼 수 있는 일이다. 사람이 직접 해야 하는 확인은 맨 아래에 따로 두었다.

- [x] 2. R015 잔향 출현·소멸 연출 — 작업 트리의 출현 예고(`announce`) 연결을 마무리하고, 체크포인트 재시작 때 연출이 남지 않는지 자동 검사한다.
- [x] 3. R023 레벨 액션 장치 — 작업 트리의 1-1·1-2 분수·잉크통·스위치 배치와 세션 연결을 마무리하고, 장치 없이도 완주되는지와 체크포인트 복원을 자동 검사한다.
